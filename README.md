# CRM Etiquetas

Extensão do Chrome que mostra um funil (Kanban) dentro do WhatsApp Web, espelhando as etiquetas do WhatsApp Business.

- **Só lê.** Não troca etiqueta, não envia mensagem e não roda nenhum código dentro do WhatsApp Web: lê a cópia das conversas que o próprio WhatsApp Web guarda no computador, a cada 5 minutos ou quando você clica em Atualizar.
- **Se atualiza sozinha** (Windows), pelo atualizador que vem no zip.

## Instalar

1. Baixe: https://github.com/pessateira/crmetiquetas/raw/main/crm-etiquetas-extensao.zip
2. Clique com o botão direito no arquivo → **Extrair tudo** → **Extrair**.
3. Na pasta extraída, dê dois cliques em **INSTALAR-ATUALIZADOR**. Se o Windows avisar, clique em **Mais informações** → **Executar assim mesmo**.
4. No Chrome, abra `chrome://extensions`, ligue o **Modo do desenvolvedor** e clique em **Carregar sem compactação**. Na barra de endereço da janela, aperte **Ctrl+V** e **Enter**, e clique em **Selecionar pasta**.
5. Abra o web.whatsapp.com e espere as conversas carregarem. O botão **CRM** aparece no canto de baixo, à esquerda.

O guia completo (`COMO-INSTALAR.md`) vem dentro do zip.

## Arquivos

- `crm-etiquetas-extensao.zip`: a extensão (é daqui que o atualizador baixa).
- `equipe/Codigo.gs`: código da planilha Google para ver o funil da equipe junto.
